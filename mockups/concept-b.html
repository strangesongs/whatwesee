Fraunces as Nameplate Bridge

Both sites use different typefaces for body text — Times New Roman on strangesongs, Space Grotesk on whatwesee. The connection: both nameplates use Fraunces, the same old-style display serif, at the top of each site. One change to strangesongs (the "cleve" heading). Everything else — layout, palette, body type — stays completely different. The name is the handshake.
